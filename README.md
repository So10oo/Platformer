# Platformer

Unity 2D platformer project (Unity **2022.3.62f1 LTS**).

## Quick start

- Install Unity **2022.3.62f1** in Unity Hub
- Open project folder: `Platformer/`
- Open scene: `Assets/Scenes/Game.unity`
- Press **Play**
