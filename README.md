# Platformer

2D-платформер на Unity **2022.3.10f1** (URP).

## Как запустить

1. Открой в Unity Hub папку `Platformer/` (это корень Unity-проекта).
2. Сцена: `Assets/Scenes/Game.unity`.
3. Play.

Управление (клавиатура + мышь):

| Действие     | Клавиша        |
|--------------|----------------|
| Движение     | WASD           |
| Прыжок       | Space          |
| Рывок (dash) | Left Shift     |
| Взаимодействие | F            |
| Атака        | ЛКМ            |
